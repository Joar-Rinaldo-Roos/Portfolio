Master’s thesis · CAISA

Tracking surgical instruments

At Skåne University Hospital in Lund, we asked whether computer vision could help prevent instruments from being left behind during pediatric open-heart surgery.

  • Computer vision
  • YOLO
  • SAM 3
  • Codex

How the results changed the question

The tracking methods we tested fell short of the reliability that task needed. We shifted to a question the data might help answer. Could patterns in which tools surgeons use, and when they switch between them, help them review surgical workflow?

Detection and tracking methods

I worked with YOLO and SAM 3 to detect and track instruments in video. I also explored whether context from the footage could help assess detections and reduce false positives.

AI-assisted workflow

I used Codex to prototype a track-repair step for the instrument-tracking pipeline. I defined what the agent should look up in the tracker CSV, how it should use findings from earlier surgeries to interpret instrument-use sequences, and when it should leave a gap unresolved. I designed the evaluation around two outcomes: correct reconnections and false merges, measured against manually annotated tracks.

Project exploration

A RAG sandbox for surgical workflow

I built a retrieval-augmented generation (RAG) sandbox around a question from my thesis: Can an agent recognize a sequence of instrument use and use it to repair a broken track?

The agent queries a three-hour tracker CSV to see which instruments appear together and how their use changes over time. It consults findings from other surgeries to interpret the sequence, then uses the observations from the current operation to propose a repair.

See a sample evaluation case

Illustrative example · simulated tracking data

Question
What activity does this sequence suggest, and which track, if any, should continue needle-driver track 17?
Retrieved CSV observations
A needle driver and forceps appeared together several times before track 17 disappeared. Two new needle-driver tracks appeared near its last position. Track 42 continued moving alongside the same forceps over the next few seconds. Track 43 moved away.
Context from earlier surgeries
During annotated suturing segments, the needle driver and forceps often worked together across several passes, with brief gaps in visibility.
Expected answer
The sequence is consistent with suturing. Propose linking track 17 to track 42 because it continued the same pattern with the forceps after the gap. The historical context helps explain the sequence, and the movement in the current CSV supports the proposed link.
What this case tests
Did the agent retrieve enough of the sequence to see what the instruments were doing together? Did that context help it choose which track to reconnect?

  • Spatial visualization

I helped design and build a cave-crawling prototype in Unity with teammates from four countries. We intended the experience for people with claustrophobia.
